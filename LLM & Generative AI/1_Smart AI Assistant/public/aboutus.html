About The Project

Intelligent Text Summarization & Generation Platform

Smart AI Workspace is a web application designed to help users interact with Large Language Models (LLMs) effortlessly. Whether you need structured text summaries, complex explanations simplified with analogies, or quick writing assistance, this platform delivers rapid AI insights.

Key Capabilities

  • Multi-mode AI processing: Summarization, Simple Concept Explanations, and Open Q&A.
  • Serverless Architecture: Built on Python Flask backend microservices hosted on Vercel.
  • Lightweight UI: High performance using native HTML5, CSS3, and JavaScript without bloat frameworks.

Technology Stack

  • Backend: Python (Flask)
  • AI Engine: Google Gemini API
  • Frontend: HTML5, CSS3, Vanilla JavaScript
  • Hosting: Vercel Serverless Architecture
